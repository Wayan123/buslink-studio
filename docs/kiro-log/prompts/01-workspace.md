## Product (decided by the owner)
BusLink Studio: one Modbus workbench for laptop, phone and browser. Tauri 2 app (Rust core + TypeScript web UI, no heavy framework unless justified):
- **Windows .exe** (desktop): Modbus RTU over a USB-RS485 adapter (the owner's adapter is a Waveshare-style "USB TO RS485 (B)" with a WCH CH343G chip; also CH340), plus Modbus TCP.
- **Android APK**: Modbus RTU over USB OTG (USB-C OTG adapter → the same USB-RS485 adapter) via a Kotlin Tauri mobile plugin using usb-serial-for-android (MIT); Modbus TCP over Wi-Fi.
- **LAN web dashboard**: the running app (desktop or Android) serves the same dashboard read-only to browsers on the LAN (token + TLS), so a supervisor can watch on any screen.
- Scope for the competition: multi-device RTU/TCP polling with one owner per bus, open versioned JSON device profiles (generic/documented/simulated/hardware-verified levels), data quality (GOOD/TIMEOUT/CRC_ERROR/EXCEPTION/STALE/DECODE_ERROR with data age), live dashboard (ISA-101 high-performance style), trends with gaps for lost communication (never interpolate over gaps), register inspector (manual address vs PDU offset, raw hex, decoded), SQLite historian, CSV/XLSX/JSON export, ISA-18.2-style alarms (hysteresis, delay, acknowledge, shelving), MQTT telemetry (Sparkplug-style or plain topics, per research), a training mode with a built-in simulator so judges can try everything without hardware, a commissioning wizard (change unit ID/baud with read-back and recovery journal), and a **control panel for a simulated VFD and temperature controller**: setpoint/run/stop through a command service with role/arming, bounds, explicit confirmation, read-back verification, audit log, and a clear "software stop is not an E-stop" label. Indonesian and English UI.
- Real hardware the owner has for testing: USB-RS485 (B) CH343G adapter, Vention USB-C OTG adapter, an Android phone (Samsung A35), and a BGT-SMPS 8-in-1 soil sensor (Modbus RTU, slave 1, 9600 8N1, FC03 from address 0, 8 registers). No VFD or temperature controller: those exist only as simulator profiles, clearly labeled.
